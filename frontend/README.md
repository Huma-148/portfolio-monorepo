# Huma Portfolio

Personal portfolio for a Full-Stack Developer & Data Engineer — Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Structure

```
src/
  app/                  # App Router entry (layout, page, globals)
  components/
    layout/             # Header, Footer, Section primitives
    sections/           # Hero, Skills, CaseStudy, Pipeline, Contact
  lib/data.ts,interface.ts           # Site content & pipeline step copy, interfaces
```

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Update contact links and copy in `src/lib/data.ts`.
